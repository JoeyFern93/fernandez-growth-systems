Install in desktop Chrome

This version installs manually from the FGS download.

  1. Extract the ZIP. On Windows, right-click it and choose Extract All. On Mac, double-click it. Keep the extracted folder on your computer.
  2. Open Chrome’s extensions page. Enter chrome://extensions in the address bar and turn on Developer mode.
  3. Choose Load unpacked. Select the extracted folder containing manifest.json. Chrome will list FGS Site Review under your extensions.
  4. Pin the extension. Open the puzzle-piece menu in Chrome’s toolbar and pin FGS Site Review so its button is easy to find.

Start your first review

Open the website in its own tab, then click the FGS icon in Chrome.

Leave a note on the live page
Choose Start reviewing, click Leave feedback in the corner, select the part you mean, and write your note.
Send a client a screenshot
Choose Capture a screenshot. Check the preview, then choose Share & copy link. Clients can open that link on a phone and pin a note without installing anything.
Continue an existing review
On an FGS review link, click the extension and choose Use this review. When the original website opens, choose Show feedback button from the extension. New notes go into that same review.

Anyone with a reviewer link can see the notes and shared screenshots for that review.
