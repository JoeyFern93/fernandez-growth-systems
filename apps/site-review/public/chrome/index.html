Site Review for Chrome

Use the extension to point out a change on a website. Each note goes into that site's shared review on FGS Site Review.

You can leave feedback from a review link on your phone.

Download extension 1.0.2 (.zip) Install or update

Leave your first note

  1. Open the website you want to review in desktop Chrome. Click the FGS icon in the toolbar and choose Leave feedback.
  2. Choose Element and click the headline, button or image you want changed. Use Point to pin an exact spot, Draw to circle an area, or Page for a general comment. Type what you want to change.
  3. Choose Send feedback. Click View notes to see the saved note.

Find the feedback later

Click the FGS icon, choose My reviews, then Open notes for the site you want. This list remembers reviews used with the extension in this Chrome profile. Future notes for that site go into the same review. To collect a separate round, use More options and choose Start a new review.

On another device, open the review link and choose Notes. To manage a review from another device, save your private owner link from Share.

Ask a client for feedback

Choose Copy client link in the extension and send it to your client. To share exactly what you see, set Screenshot area to Visible area or Full page. Choose Capture a screenshot, check the image and choose Share & copy link. A client can scroll through the full-page image and mark any section.

Anyone with the reviewer link can read the notes and see shared screenshots for that review.

Use the extension with a review link you already have

Open that link, click the FGS icon and choose Use this review. Once the original site opens, click the extension and choose Leave feedback. Your notes will go into that existing review.

Received a review link?

Open the link on your phone or computer and tap Leave feedback. Choose the kind of feedback you want to leave, mark the page if needed, type your note and tap Send feedback. The person who sent the link can read it under Notes. No account or installation is needed.

What if the website won't open in the review?

Use Page to write a general note. Choose Full-page screenshot and then Capture full page to open a scrollable image of a public page. Scroll to the section you want, then choose Point or Draw. Open Notes to see the mark on that saved image. For an exact Element on a site that isn't connected, use the desktop extension on the original website.

Install or update in desktop Chrome

Install for the first time
  1. Download and extract the ZIP. On Windows, right-click it and choose Extract All. On Mac, double-click it. Keep the extracted folder on your computer.
  2. Enter chrome://extensions in Chrome's address bar and turn on Developer mode.
  3. Choose Load unpacked and select the folder containing manifest.json.
  4. Open the puzzle-piece menu in Chrome's toolbar and pin FGS Site Review.
Update an existing installation

Download the new ZIP and extract it into the same folder you chose when you installed FGS Site Review. Replace the old files. Open chrome://extensions and click the reload icon on the FGS Site Review card. Its version should read 1.0.2.
