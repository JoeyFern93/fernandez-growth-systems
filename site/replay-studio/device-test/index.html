Frame check

Compare a phone original, a TV replay export and a native camera recording using footage of the same moving subject. Files stay on this device.

Record the Galaxy S25 Ultra comparison
  1. Mount the phone and mark both edges of the court in the shot. In bright light, film a continuously moving, textured object. Keep the position and zoom fixed. Record at least 10 seconds per setting.
  2. In Replay Studio, test 1080p at 120 FPS and 720p at 120 FPS. Try each rear lens the browser exposes. Save the phone original, the TV export of the same movement, and each device’s diagnostics. Note which edge markers are inside the frame.
  3. Repeat in the native camera using the widest lens that actually permits high-rate capture. If slow motion changes playback duration, measure the real interval covered by the entire file using a separate timer. Use that interval below.
  4. For two angles, include the same visible timer in both shots, at the start and ten minutes later. Compare the timer readings on paused frames after normal play and after scrubbing. A display timer can measure timing but its refresh rate can limit the visible changes. Use a moving physical subject for high-frame-rate checks.
